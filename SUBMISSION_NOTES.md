# Devpost submission checklist

Before submitting this project:

- [ ] Run the app locally and test create/edit/complete/filter/search/export flows.
- [ ] Replace any placeholder claims in the Devpost story with features actually implemented.
- [ ] If entering a device-specific Amazon track, implement its required integration and verify the official rules.
- [ ] Do not claim an Amazon service or AI model is connected unless it is implemented and tested.
- [ ] Push all source files to a GitHub repository.
- [ ] Ensure the repository is public or shared with the organizers as required by the rules.
- [ ] Add a public open-source license (MIT is included here).
- [ ] Capture screenshots of the running app.
- [ ] Record and upload a real demo video to YouTube or Vimeo, then add its actual URL to Devpost.
